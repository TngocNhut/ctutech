LUMA original procedural device illustrations

demo-phone.glb and demo-laptop.glb were authored for this project using
scripts/generate-demo-models.py. They contain original geometry and materials,
without downloaded product models, brand logos, photographs or external buffers.
They illustrate generic device shapes, not the exact selected brand/model/SKU.
Regenerate them with the included Python script (standard library only).

Viewer: @google/model-viewer 4.4.0, self-hosted unchanged in /vendor.
Its Apache-2.0 license is included as /vendor/model-viewer-LICENSE.txt.
Official viewer documentation: https://modelviewer.dev/
Format specification: https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html
Validated with Khronos glTF Validator 2.0.0-dev.3.10.
